# QR Smart Menu - Pokolane

QR Smart Menu - Pokolane is a restaurant menu web application. Customers can scan a QR code, view the menu, choose food items, adjust quantity, add special requests to the chef, and see the total price.

## Project Features

- Customer food menu page
- Search food item
- Filter food by category
- Add and remove food quantity
- Automatic total price calculation
- Request to chef text box
- Admin login page
- Admin dashboard
- View customer orders
- Add, update, and delete food items
- QR code generator for restaurant tables
- Data saved using browser localStorage

## Technology Used

- HTML
- CSS
- JavaScript
- localStorage
- GitHub Pages

## Pages

- `menu.html` - Customer menu page
- `admin-login.html` - Admin login page
- `admin.html` - Admin dashboard
- `qrcodes.html` - QR code generator page
